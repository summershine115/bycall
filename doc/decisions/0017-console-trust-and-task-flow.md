# ADR-0017：控制台可信配置与任务闭环

- **状态**：已采纳（2026-10-18 用户明确要求实施；实现与验证进度见执行计划 T3.8）
- **关联**：ADR-0013、ADR-0014；架构红线保持不变。

## 背景

前端审查发现实例分区提交字段与 API 不一致、快照共享引用、保存跨区清除草稿标记、失败被当成空数据，以及审批缺少最终参数确认等问题。用户要求实施优化方案并启动、视觉与静态复查。

## 决策

1. 保留八项导航、Hub 与详情分区；按分区提交真实字段，以保存响应更新该区基线，其他草稿保留；数组深复制，保存期间锁定编辑，离开前保护草稿，凭证不存浏览器持久存储。
2. 显式表达继承、限制与补充模式，不修改现有权限语义。生效预览调用治理脊柱；清楚区分绑定配置与运行结果，草稿不参与模拟，结果在相关保存后失效，忽略迟到响应。
3. 配置检查只陈述已有数据，不以填表完成冒充上线或测试通过。渠道保存成功与连接成功分别反馈。
4. 审批确认展示申请人、渠道、关联记录及原始参数；持续授权明确范围，永久授权二次确认；提供兼容的新增分页端点，既有列表响应不变。
5. 统一局部错误、刷新失败保留旧值、时间及空态；知识库可检索性只来自已发布索引状态。首页待处理事项前置，运行记录用真实关联键跳转并保留筛选。
6. 使用现有主题 Token，补齐窄屏、焦点与输入法处理。此次属于用户明确要求的可用性修复，恢复范围限 T3.8，不解冻其他新能力。

## 后果

新增控制面分页查询，无数据库迁移；不改变授权匹配、工具执行或检索预过滤。完整模型/提示词会话解析仅在有真实上下文时才可展示；当前无会话预览标明边界。自动化、浏览器检查及限制以 T3.8 验收记录为准。
