## 浏览器复查

使用 ego-browser 技能检查；其 CDP 截图超时后，改用同一项目的现有 Chrome 页面完成截图与交互检查。复查在 `/tmp/bycall-ux-preview/` 的独立 SQLite 数据库执行，未向真实 IM 发送消息或调用外部模型。

已实测：

- 模型草稿未保存时切到基础信息并保存，模型草稿仍保留；放弃修改回到继承值。
- 模型选择保存后接口回读 `model_id=1`；知识域数组 public、可见角色数组 ux-review 保存后重新加载正常。
- 自定义范围未选择项目时提示错误；嵌套响应式数组加载错误在复查中发现并修复，加入回归测试。
- 390×844 窄屏、1280×900 与 1440×900 桌面布局；修复手机顶栏挤压和分区导航过长；深色预览文字、状态与层次可辨。
- 策略预览选择复查用户后显示实际权限、检查时间和绑定说明。
- 审批确认展示完整参数；批准不存在的本地测试工具后显示明确失败原因；详情可跳转任务，任务可跳转来源会话，会话消息可查看审批失败回执。

截图是本机复查证据，未随代码提交；保存在 Codex 当前会话的 visualizations 目录（agent-desktop.png、agent-mobile.png、agent-preview-dark.png、approval-confirmation.png）。

## 启动与边界

集成后从主目录启动：

```sh
make dev
npm run dev --prefix frontend -- --host 127.0.0.1
```

前端 `http://127.0.0.1:5173/`，API `http://127.0.0.1:8000/`。实际启动采用主目录已有环境配置；隔离复查数据不导入主数据库。

本次不把模型绑定说明当成完整的会话/灰度解析，也不把可检索发布状态当成业务召回质量认证；真实模型回答质量、真实企微/飞书凭证连接仍需对应环境验证。审计数据模型没有完整的会话关联键，入口如实显示为用户审计记录。新增分页接口保持旧审批数组接口兼容，无数据库迁移。
