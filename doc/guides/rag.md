# RAG 运行行为与验证

> 状态：批次 1–3 实现；2026-10-15。决策见 [ADR-0016](../decisions/0016-rag-publication-and-evidence.md)，
> 当前范围对应执行计划 T1.1、T1.9、T2.1、T3.2。

## 入库与权限

每次入库生成独立索引代。全部 embedding 校验、向量写入、flush 成功后，SQL 事务
同时提交有效代、文档 completed 状态与统计。失败代、未发布代不会进入召回白名单。
重建失败会保留物理旧索引，但 failed 文档暂不可检索；ACL 修改失败恢复旧权限和旧
状态。旧代清理失败只留下不可检索的数据，后续重建或删文档时再清理。

检索先限制可见 KB，再依据当前 SQL 文档 ACL、completed 状态与有效代构造 doc_id
白名单。向量查询还附加 source、level 和 chunk_type=child 条件。父块在同一 KB 内
精确读取：先只取授权元数据，通过同文档、同代和 ACL 检查后才读取正文。

无登记的旧文档只允许 completed 的 `doc_<id>` 索引；原来 failed/processing 的文档
应由管理员重新入库。旧 zvec 若缺少 chunk_type 等字段，检索会报故障并关闭该库
召回，应重新建立索引；本次未执行部署数据库迁移或修改实际知识库。

## 候选与分数

每库默认召回 20 条，在默认 80 条总候选内轮转收集、同父块去重，再统一排序，
默认返回最多 5 条。管理员可通过角色 context_budget 覆盖以下字段：

| 字段 | 默认值 | 边界与作用 |
|---|---:|---|
| rag_topk | 5 | 1–50，最终条数上限 |
| rag_candidate_topk | 20 | 至少最终条数，最多 50，每库候选上限 |
| rag_candidate_max_total | 80 | 至少最终条数，最多 200，统一排序池上限 |
| rag_min_rerank_score | 0.0 | 0–1，只对已配置 reranker 生效；零分不注入 |
| rag_min_score_ratio | 0.25 | 0–1，仅裁剪 rerank 分数低于本轮最大值比例的片段 |
| rag_chunk_max_chars | 1200 | 1–10000，单块字符上限 |
| rag_context_max_chars | 6000 | 1–50000，资料块含标题、分隔符的字符上限 |

全局激活的 rerank 模型对同一个候选集评分，非法数量/索引/非有限值等结果视为失败。
未配置或调用失败时，以统一候选集上的 BM25 关键词分数排序（英文词、中文双字）；
无关键词交集不注入，检索状态明确标为 degraded。该降级会漏掉同义表达，需要
配置适用的 reranker 和实际业务语料评测。KB 内向量与 FTS 仍用 RRF 融合召回。

RRF 排名分与 BM25 分均标为“未校准”，不作为置信度；rerank 档位只描述本候选集
内的相对分数，也不是回答正确率。默认阈值没有经过业务校准，不能据此宣称已具备
可靠的无答案识别；真实模型阈值需按标注语料设置。

## 多轮、故障与证据

有知识库、知识权限与会话历史时，检索前用当前对话模型与同会话最近六条历史改写
问题（每条历史最多 300 字）；改写只接受 2–512 字纯文本，失败回退原问题。最终
回答仍使用用户原始问题，改写不参与授权。当前额外改写请求沿用对话模型的请求
超时，故障时可能增加延迟；它不改变会话/实例隔离键。

| 检索状态 | 含义 |
|---|---|
| not_requested | 无可检索 KB 或无知识权限，未启动检索 |
| no_hit | 完成查询但无候选或未过重排阈值 |
| ok | 取得证据且没有检索降级 |
| degraded | embedding/父块/部分 KB 故障，或关键词排序降级；可以没有证据 |
| error | 所有尝试的 KB 检索均失败，没有证据 |

状态与阶段/错误码写入 context_trace；`/chat` 与 `/chat/stream` 的 done 响应新增
retrieval_status、retrieval_diagnostics，管理检索响应有 retrieval_status、diagnostics。
故障和降级还由运行时在回答末尾附加说明，同步与流式一致。错误细节留在服务日志，
用户回复不暴露原始异常。无证据时提示模型说明资料不足，不允许声称有知识库依据。

预算化后才建立证据：每条资料有本轮 E 编号、稳定 KB/doc/chunk ID，引用 snippet
对应实际注入的截断文本。预算丢弃、低分裁剪、去重后的资料不出现在引用列表。
返回的来源表示提供给模型的证据，尚未验证回答的每一句是否被证据支持；模型生成
的 E 引用也未做逐句核验。检索与引用回归说明见 [评测指南](evaluation.md)。
